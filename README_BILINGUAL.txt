KM SystemWorks bilingual site (based on Japanese Ver.6)

Upload the CONTENTS of this ZIP to the root of the GitHub Pages repository.
Japanese: https://kmsysworks.com/
English:  https://kmsysworks.com/en/

Both pages use the same assets, styles, scripts and portfolio-data.js.
Use portfolio-editor.html for portfolio changes; the resulting portfolio-data.js must be placed at the root.
Optional English portfolio fields: title_en and description_en; without them, original Japanese text is shown.
The email address is not active until configured and tested.
Check the contact phone number before publishing.
